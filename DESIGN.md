# Compact — краткий технический дизайн

## Цель

`compact.js` — самостоятельный каталог для Lampa на webOS 3.5 / Chromium 38. Он не
заменяет и не загружает резервный `s.js`, не меняет глобальный размер интерфейса и
не подменяет методы Lampa.

## Экран и навигация

Главная регистрирует независимые ряды через `Lampa.ContentRows`:

1. Новинки / Русское / Детское.
2. Глобальные сервисы.
3. Российские сервисы.
4. Жанры фильмов и сериалов (раздельные TMDB id).
5. Тренды недели: фильмы.
6. Тренды недели: сериалы.
7. Качественные новинки.
8. Одна тематическая подборка, меняющаяся раз в неделю.

Навигационные ряды возвращаются синхронно. Сетевые ряды проходят через одну
очередь с максимум двумя активными запросами. Переход с логотипа или жанра
открывает стандартный `category_full`; источник `compact` загружает нужную
страницу TMDB и поэтому каталог не ограничен размером ряда на главной.

Перед открытием стримингового сервиса показывается простой список сортировок.
Наборы сортировок различаются для фильмов и сериалов.

## Данные, фильтры и отказоустойчивость

- Единственная сеть — штатный адрес, возвращаемый `Lampa.TMDB.api()`.
- Логотипы провайдеров загружаются со штатного CDN TMDB; сведения о
  доступности провайдеров предоставлены JustWatch.
- Тайм-аут запроса: 6,5 секунды.
- Один fallback разрешён только при ошибке или полностью пустом результате.
- Дубликаты удаляются по ключу `media_type:id`.
- Даты новинок вычисляются при каждом запросе.
- Возрастной режим исключает `adult` и консервативный набор жанров; это
  эвристика, потому что TMDB discover-ответ не содержит возрастной рейтинг
  каждой карточки.
- Кириллица проверяется в локализованном названии и описании.
- Нежелательные слова проверяются в названии и описании без учёта регистра.

## Кэш

В `Lampa.Storage` хранится только компактная форма карточек. Свежесть — 8 часов,
допустимый stale-показ — 7 дней. Stale данные отдаются сразу, после чего один
фоновый запрос обновляет запись. Ошибка обновления не стирает рабочий кэш.
Индекс ограничен 36 страницами; самые старые записи удаляются.

## Совместимость

Runtime написан как ES5 IIFE. Не используются Promise, `async/await`, стрелочные
функции, `let`/`const`, template literals, optional chaining и современные методы
массивов. Тест запускает файл в VM с минимальным mock Lampa и отдельно сканирует
запрещённые конструкции.
