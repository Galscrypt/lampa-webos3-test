# Compact для Lampa

Небольшой каталог для старых телевизоров LG с webOS 3.5. Рабочий резервный
плагин `s.js` проект не изменяет.

## Проверка на компьютере

Нужен Node.js. В папке проекта выполните:

```powershell
npm test
```

Проверяются синтаксис, ES5-ограничения, реальный контракт событий `ContentRows`,
поля локальных и TMDB-изображений, регистрация рядов и источника, очередь
запросов, фильтрация, кэш и тайм-аут.

Данные о доступности фильмов и сериалов у провайдеров поступают через TMDB и
предоставлены JustWatch. Атрибуция также показывается в заголовках провайдерских
рядов внутри Lampa.

## Тест на телевизоре без публикации

1. Запустите в этой папке простой HTTP-сервер, например
   `python -m http.server 8000`.
2. Узнайте локальный IP компьютера, например `192.168.1.20`.
3. Убедитесь, что телевизор и компьютер находятся в одной сети.
4. В Lampa откройте **Настройки → Расширения → Добавить плагин** и укажите
   `http://192.168.1.20:8000/compact.js`.
5. Полностью перезапустите Lampa. На главной появятся ряды Compact, а в
   настройках — раздел **Compact**.

Если Lampa открыта по HTTPS и блокирует локальный HTTP, временно разместите файл
на своём HTTPS-хостинге или используйте локальный HTTPS-сервер. Публикация в этом
репозитории намеренно не настроена.

Для возврата к резерву удалите URL `compact.js` из расширений и оставьте прежний
`https://galscrypt.github.io/lampa-webos3-test/s.js`.
